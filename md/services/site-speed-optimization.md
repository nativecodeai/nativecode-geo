Field data vs lab data

## How does Google measure site speed?

Google measures site speed with field data from real Chrome users in the Chrome UX Report (CrUX), and assesses Core Web Vitals at the 75th percentile of page visits.

1. Largest Contentful Paint (LCP): how long the main image or text block takes to appear.
2. Interaction to Next Paint (INP): how quickly the page responds to taps, clicks and key presses.
3. Cumulative Layout Shift (CLS): how much the layout jumps while the page loads.
4. Field data: real-user CrUX results shown in Search Console and PageSpeed Insights over a rolling 28-day window.
5. Lab data: Lighthouse tests run in a controlled setting, useful for debugging but not what Google uses to assess Core Web Vitals.

## Questions about site speed optimization

### What is site speed optimization?

Site speed optimization is the work of making web pages load faster, respond sooner and stay visually stable for real visitors. It covers images, fonts, JavaScript, third-party scripts, theme code, caching and CDN setup. The goal is to pass Google's Core Web Vitals in field data and give visitors a faster experience, especially on mobile.

### Why is my PageSpeed Insights score different from Search Console?

They often show different data. The PageSpeed Insights performance score comes from a single Lighthouse lab test on a simulated device. The Search Console Core Web Vitals report uses field data from real Chrome users over a rolling 28-day window. Google assesses Core Web Vitals on field data, so we use lab tests to debug and field data to judge progress.

### Do Shopify apps slow down a store?

They can. Many Shopify apps add their own JavaScript, CSS and network requests to every page, even pages where the app is not used, and code from uninstalled apps can stay in the theme. We review each app and tag, remove what is unused, load the rest only where it is needed, and consolidate tracking in one tag manager setup.

### Does site speed affect conversions?

Speed can affect conversions, but the size of the effect differs by site, so we do not promise a set lift. Slow product pages, laggy filters and layout shifts during checkout add friction for buyers. We compare conversion rate by template in GA4 before and after speed releases, and pair speed work with conversion rate optimization when testing is needed.

### How long does site speed optimization take?

The first round of fixes usually takes a few weeks, depending on the platform, the number of templates and how many apps and scripts are involved. Lab results change as soon as a fix is released. Field data in CrUX and Search Console updates over a rolling 28-day window, so confirmed Core Web Vitals changes take about a month to show.
