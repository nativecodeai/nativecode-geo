Questions

## Server-side tracking questions

### What is server-side tracking?

Server-side tracking sends conversion events from a server you control to analytics and ad platforms, instead of relying only on scripts in the visitor's browser. A server-side Google Tag Manager container or a platform conversions API receives each event, adds the details the platform needs and forwards it. Ad blockers and browser limits affect it less, and you control what data is shared.

### Why do browser pixels miss conversions?

Browser pixels miss conversions because ad blockers stop them from loading, browsers such as Safari limit cookies and click identifiers, and visitors who decline consent are not tracked. Checkouts on other domains and slow pages drop events too. Meta, Google Ads and TikTok then see fewer conversions than really happened, which weakens their bidding and makes campaigns look worse than they are.

### What is the Meta Conversions API and do we need it?

The Meta Conversions API sends events such as purchases and leads from your server directly to Meta. Most brands running Facebook and Instagram ads benefit from it, because it recovers events the Meta Pixel misses and improves event match quality. We run it alongside the pixel with shared event IDs, so Meta counts each conversion once.

### How do you avoid double counting conversions?

We avoid double counting with deduplication. Each conversion gets one event ID that is sent with both the browser event and the server event, and platforms such as Meta and TikTok use it to keep only one. For Google Ads we use enhanced conversions with transaction IDs. We then compare platform numbers with orders or CRM leads to confirm the counts line up.

### Does server-side tracking work with Shopify?

Yes. On Shopify we use customer events and web pixels, which work with Checkout Extensibility, and send events to a server-side Google Tag Manager container or straight to platform APIs. The Meta and Google sales channel apps for Shopify also send server events, so we check what they already cover before adding anything, to avoid duplicates.
