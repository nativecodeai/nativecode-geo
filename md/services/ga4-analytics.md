## GA4 setup and analytics questions

### What is the difference between GA4 and Google Tag Manager?

GA4 is the analytics tool that stores and reports your data, and Google Tag Manager is the tool that sends data to it. Tag Manager holds the tags and triggers that fire when someone views a page, submits a form or buys. Using both keeps tracking changes out of your site code and makes them easier to test.

### Can you fix a GA4 property that is already set up?

Yes. Most of our GA4 work starts with an existing property. We audit the data streams, events, conversions and settings, find duplicate or missing tracking, and fix it in Google Tag Manager without losing the history you already have. Where a rebuild is the cleaner option, we explain why before making any change.

### Do you set up ecommerce tracking for Shopify?

Yes. We set up GA4 ecommerce tracking on Shopify, Webflow and WordPress stores, covering product views, add to cart, checkout steps and purchases with revenue. On Shopify we work with its customer events and checkout settings, and we compare GA4 revenue with store orders so the numbers can be trusted.

### What is Google consent mode and do we need it?

Google consent mode adjusts how Google tags behave based on the choice a visitor makes in your cookie banner. If you run Google Ads or have visitors from regions with consent rules, such as the European Economic Area, it needs to be set up correctly. We connect it to your consent tool and test each consent state.

### How do you connect GA4 data to our CRM?

We capture UTM parameters, the Google Ads click ID and the landing page on each form submission, then pass them into your CRM with every lead. That shows which channel and campaign produced each lead and customer, not only which one produced the form fill. We then report on those results in Looker Studio.
