For developers

Connect the MCP server

git clone https://github.com/nativecodeai/nativecode-geo
cd nativecode-geo/mcp-server && npm install && npm run build
claude mcp add nativecode-audit -- node "$PWD/dist/index.js"

Then ask: "Audit nativecode.ai for AI search readiness and give me the quick wins."
